# Royal Bridges HR & Recruitment Consultancy

A separate, private website project for the Royal Bridges recruitment and HR consultancy division.

## Preview locally
Open `index.html` in a browser. The site is a static front-end preview and is not connected to a database or published hosting.

## Current pages/sections
- Home
- Employer enquiries
- Candidate enquiries
- Recruitment and HR services
- About
- Contact

## Important before launch
- Confirm the exact legal business name, licence and permitted UAE activities.
- Confirm whether the recruitment business has the approvals required for each service offered.
- Add an approved privacy notice and candidate data-retention process before collecting CVs or personal information.
- Connect enquiry and CV forms to a secure backend before accepting live submissions. The current contact form only prepares an email using the visitor's email application.
- Replace stock photography and confirm image licensing before public launch.
- Confirm final contact details, social links and branding.

This repository is private and this project has not been deployed or published.
